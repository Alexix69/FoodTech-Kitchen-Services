	## 1. PRD

- Se verifica en primer lugar qué documento se va a construir para tener claro el objetivo final.
- Para ello se consultaron diversas fuentes con el fin de conceptualizar qué es el documento, qué contiene y cómo se estructura correctamente.
- Lo que se obtuvo llevó a decidir crear un PRD basado en teoría ágil.
- Se toma la plantilla de Confluence como base para el documento oficial.
- Se conceptualiza el modelo de trabajo que ofrece Atlassian para la creación de un documento de requisitos de producto.
